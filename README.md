# LOOP: Последний цикл

Неоновая 2D головоломка о свете, тенях и памяти. Главный герой — Арзон, маленький дух света; его спутник — Пуши.

## Технологии
- Phaser 3
- JavaScript modules
- HTML5 + CSS
- Phaser подключается через CDN, сборка и платные сервисы для первого запуска не нужны.

## Запуск
Откройте `index.html` через локальный сервер (например, расширение Live Server в VS Code) либо опубликуйте репозиторий через GitHub Pages.

## Управление в демо
- A / D или ← / → — движение
- W / ↑ / Space — прыжок
- Перетаскивание светящейся лампы мышью — изменение положения источника света
- R — перезапуск уровня

## Статус
Ранний игровой прототип. Первая сцена знакомит с Арзоном, Пуши и базовой головоломкой с тенью-мостом. Механика будет расширяться по результатам тестирования.

## Структура
- `src/scenes` — игровые сцены
- `src/characters` — персонажи
- `src/mechanics` — игровые механики
- `assets` — изображения, звук и музыка
- `levels` — данные уровней
